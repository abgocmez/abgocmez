## 🔧 Featured projects

**[Edge Telemetry Gateway](https://github.com/abgocmez/Edge-Telemetry-Gateway)** — C++20, Linux SocketCAN
Multi-threaded service that ingests CAN/LIN frames from several buses, sequences them and streams them to independent consumers. Explicit handling of message loss and timeouts (gap markers, per-ID cadence monitor). Measured on a Raspberry Pi 3 B+: 3.56M frames with zero loss.

**LIN Bus Fault Injection Framework** — STM32 + TJA1020, C, KiCad · *Best Final Project Award*
Custom LIN node hardware and firmware that injects checksum, timeout and no-response faults for automotive network testing. Validated over 5 × 1000 trials with logic analyzer captures; journal manuscript in preparation.

**Current-Controlled Microstepping Stepper Driver** — STM32F446, custom PCB
Driver board and firmware implementing current-controlled microstepping, brought up and debugged on real hardware.

**FPGA Digital Guitar Effects Pedal** — Verilog · hobby project
